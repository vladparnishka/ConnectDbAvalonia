# Информационная система для базы отдыха

Курсовой проект по МДК.01.01 «Разработка программных модулей».
Студент: Шестаков В.В. (Группа 320).

## Описание
Приложение для автоматизации учета и бронирования домиков на базе отдыха.

## Технологии
* Язык программирования: C#
* Фреймворк интерфейса: Avalonia UI
* База данных: Microsoft SQL Server
* ORM: Entity Framework Core

## Функционал
* Просмотр каталога домиков
* Оформление бронирования с расчетом стоимости и скидок
* Разграничение прав доступа (Клиент, Менеджер, Администратор)
* Просмотр списка оформленных броней
